JS Chess

A simple chess game built in JavaScript as a personal learning project.  
This project focuses on implementing chess rules, move validation, and basic game logic in the browser.

 Features

- Move validation for all chess pieces
- Board setup with standard chess starting positions
- Interactive UI with drag-and-drop functionality
- Responsive design using HTML/CSS
- Learning project for practicing JavaScript fundamentals

 Technologies

- HTML5
- CSS3
- JavaScript 

1. Clone the repository:

```bash
git clone https://github.com/DevByEma/js-chess.git
```

 2.Open index.html in your browser.

3. Start playing!
